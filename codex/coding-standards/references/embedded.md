# 嵌入式规范

涉及 HAL、OSAL、驱动、寄存器、`volatile`、定长类型、数值计算或内存策略时读取本模块。

- 设计 HAL 和 OSAL 隔离软硬件，便于移植 **[建议]**。
- 优先使用工程已定义的定长类型，如 `UINT8`、`INT32U`；模块已统一使用 C99 标准类型时可沿用 `<stdint.h>`。
- 优先选择整型，避免浮点；适合时将浮点运算转换为整数或定点运算。
- 除确需负数外，优先使用无符号类型。
- 禁止对有符号整型执行移位操作。
- 操作数组下标前必须检测范围。
- 使用单精度 `float` 代替 `double`，并使用后缀 `F` 明确单精度常量。
- 使用模块和工具链已支持的单精度数学接口，如 `sinf()`；资源受限时优先考虑定点或整数算法。
- 类型转换时明确写出目标类型。
- 优先使用静态内存分配，避免动态分配 **[建议]**。
- 使用动态分配时，资源不再使用后必须释放并将指针置为 `NULL`。
- 使用 `const` 常量化只读数据，节省 RAM 并防止意外修改。
- 与硬件关联、被中断或多线程修改、直接映射硬件寄存器的数据使用 `volatile`。
