# 命名规范

新增、重命名或审查函数、参数、变量、常量、枚举和全局符号时读取本模块。

## 命名规则

- 使用工程现有匈牙利前缀：`u8`、`u16`、`u32`、`i8`、`i16`、`i32`、`f32`、`f64`、`b`、`p`、`c`、`str`、`s_`、`g_` 等。
- 命名必须有明确含义，避免二义性。
- 禁止仅通过大小写区分不同命名。
- 有约定俗成的缩写时使用缩写；缩写可能产生歧义时使用全拼。
- 禁止以下划线开头。
- 禁止使用语言关键字命名。
- 禁止使用非英语命名，例如汉语拼音。
- 命名长度不超过 4 个单词。
- 枚举命名使用 Pascal 规则，如 `FileMode`。
- 函数命名使用 Pascal 规则，如 `ConnectPort()` **[建议]**。
- 函数参数命名使用 Camel 规则，如 `portConnection` **[建议]**。
- 局部变量命名使用 Camel 规则，如 `portConnection` **[建议]**。
- 全局变量以 `g_` 开头，如 `g_isEnable` **[建议]**。
- 静态变量以 `s_` 开头，如 `s_counter` **[建议]**。
- 局部变量禁止与外部变量、全局变量、静态变量或函数名重名。
- 新增命名优先服从目标模块已有且一致的命名约定，避免无关批量重命名。
