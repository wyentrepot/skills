# REQS-INDEX.md — 需求索引

> 项目级索引，列出所有需求、状态与所属分支。
> 会话开始先读本文件，定位"本次做哪个需求"（决策 #2：多需求切分 + 上下文隔离）。

## 当前需求

| ID | 标题 | 类型 | 状态 | 所属分支 | 更新时间 |
|----|------|------|------|----------|----------|
| 0001 | <需求标题> | 大需求/临时小需求 | 🔄 进行中 / ⏸ 已挂起 / ✅ 已完成 | <branch-name> | YYYY-MM-DD |

## 使用说明

- 新建需求：创建 `reqs/<id>-<slug>/` 目录（REQS.md / TODO.md / DONE.md），在此表登记一行。
- 切换需求 = 切 git 分支（决策 #2）；切分支前确认当前需求 TODO 进度已保存。
- 需求完成 → 状态改「✅ 已完成」，日志归档到 DONE.md。
- 临时小需求可快速进出；大需求在 TODO.md 分阶段推进。
