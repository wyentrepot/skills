# 知识库查阅（渐进式加载）

## 核心原则

1. **先查库，再回答**。本库（112 个 md）是国网/南网协议与业务的一手蒸馏资料。凡协议帧字段、数据单元标识、状态机参数、省份扩展细节，一律查库后回答。训练记忆对常见项（如 645 起始符 68H）也许碰巧正确，但对冷门项（省扩展 DA 映射、CCO 轮次参数）必然含糊或编造。
2. **渐进式加载**：L0 索引（几百 token）→ L1 关键词+同义词定位 → L2 按需读小节+片段。禁止整读 40KB 大卡、更禁止把整库塞进上下文。
3. **输出契约**：每个结论必须带「文件路径 + 小节标题 + 原文片段(3~8 行)」。

## 库路径与地图

- 库路径：`/01-workfile-ai/04-obsidian/obsidian`（其他环境按实际挂载路径替换）
- **先读技能基目录下的 `vault-map.md`**（本技能文件同目录，如 `$DSH_HOME/skills/knowledge-lookup/vault-map.md`，不在库内）：目录结构、编号规则、领域同义词表、分诊规则、注意点（第一次查库时读，之后可跳过）
- 快速导航：`总索引.md`（卡名+摘要）、`00_总述.md`（覆盖范围）、`07_总结.md`（协议分层关系）、`CCO实现逻辑/00-总览.md`（代码落地索引）、`CCO实现逻辑/13-文档与代码差异记录.md`（差异先看它）
- 经验沉淀区：库根 `经验索引.md`（查库前先扫一眼，查完追加）

## 流程

### L0 常驻索引
1. 读 `总索引.md`（62+ 张卡名与摘要）建立地图
2. 涉及 CCO 实现时再读 `CCO实现逻辑/00-总览.md`
3. ⚠️ 总索引链接带失效前缀 `蒸馏/`——**一律按 basename 定位文件，不直接信任链接路径**；索引略滞后（实际 75 卡），检索必须带 glob/grep 兜底

### L1 关键词 → 同义词 → 定位
1. 提取用户关键词（含口语/简写）
2. 同义词扩展（三层）：`vault-map.md` 领域同义词表 → 卡 frontmatter `aliases` → `tags`/`title`
3. 定位手段（按序）：basename glob `*关键词*` → aliases → tags → title → 全文 `grep -rn "<关键词>" 协议层 业务层 南网 05_省份协议 CCO实现逻辑`
4. 分诊（决定优先看哪层）：
   - 帧格式/协议/字段/校验 → `协议层/`（南网 → `南网/协议层/`）
   - 业务逻辑/方案/流程 → `业务层/`（省份 → `05_省份协议/` 或对应省业务卡）
   - 代码落地/调用链/状态机 → `CCO实现逻辑/`
   - 差异 → `CCO实现逻辑/13-文档与代码差异记录.md`

### L2 定位 + 片段
1. 命中卡后 `grep -n` 找关键词行号，再 read 该小节（`##` 标题上下），引用 3~8 行原文
2. 多命中按问题类型排序（帧→协议层、业务→业务层、代码→CCO），给 top 2~3，说明排除其余的理由
3. 歧义（同一关键词协议层/代码层两处都有）→ 分开标注出处，不合并
4. 卡内数据自相矛盾或与原文不一致 → **诚实标注**（参考 `CCO实现逻辑/13`），需要字节级细节时指出原文在 ima 知识库（卡 `source` 双链），不强行圆场

## 输出契约（每个答案必填）

```
【位置】<相对路径> / ## <小节标题>
【片段】<3~8 行原文引用>
【来源】文档（蒸馏卡） | 代码（template/文件:行号） | 经验/推测 —— 必须区分
```

- 找不到就明说「库内无此内容」，禁止用训练记忆补
- 给「用户问题的直接答案 + 出处」，不空泛复述文档

## 经验沉淀（每次查询后）

- 有非显然发现（新同义词、跨卡关联、踩坑、差异、省差异、检索技巧）→ 向库根 `经验索引.md` 追加一行：
  `- YYYY-MM-DD [关键词]：一句话经验（位置）`
- 已有条目不重复；一句话，不写长文；不记录显然内容

## 常见错误（Red Flags）

| 错误 | 修正 |
| --- | --- |
| 凭记忆答帧字段/状态机参数（尤其省扩展、CCO 参数） | 查库；记忆对冷门项必错 |
| 会话里根本没意识到有库可查 | 本技能存在即触发；凡协议问题先想库 |
| 直接信总索引的 `蒸馏/` 链接路径 | 按 basename glob 定位 |
| 整读 40KB 卡文件 | 先 grep 定位小节，只读该小节 |
| 只给结论不给位置+片段 | 输出契约必填 |
| 卡内矛盾强行圆场 | 诚实标注，指原文附录 |
| 查完不沉淀经验 | 追加 `经验索引.md` |
